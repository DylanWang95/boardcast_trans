# 🌅 2026-03-31 海外宏观与市场博弈晨报

# 一、关注要点

* **【主题关键词】伊朗战争与霍尔木兹海峡局势**
  * **客观事实/量化数据**：
    1. 美国总统特朗普已告知幕僚，愿意在不重新开放霍尔木兹海峡的情况下结束对伊朗的战争，因为重新开放海峡的任务可能将冲突延长至其设定的4-6周时间表之外。（WSJ, Bloomberg, Marketplace, NPR）
    2. 一艘科威特油轮在迪拜附近被无人机击中，凸显了关键航运路线面临的威胁。（WSJ, Bloomberg）
    3. 伊朗无人机袭击了停靠在迪拜的一艘满载的科威特油轮。（Bloomberg）
    4. 霍尔木兹海峡目前基本处于关闭状态，仅有少量船只（如每日2艘巴基斯坦船只）被允许通过，远低于战前水平。（NPR）
    5. 美国向中东地区增派了数千名士兵（包括海军陆战队和第82空降师），使该地区美军总数达到约5万人。（NPR）
  * **共识与分歧**：
    * **共识**：所有播客均报道了特朗普考虑在不重新开放霍尔木兹海峡的情况下结束战争的消息，并指出此举可能意味着伊朗将维持对该水道的控制。战争已进入第五周，接近特朗普设定的时间表上限。（WSJ, Bloomberg, Marketplace, NPR）
    * **分歧**：关于特朗普的真实意图和最终行动存在不确定性。
        * **WSJ** 和 **Marketplace** 侧重于报道这一政策选项本身及其对市场（股市反弹、油价高企）的直接影响。
        * **Bloomberg** 的分析（通过记者Dan Williams）指出，特朗普的言论可能相互矛盾，旨在制造“战术烟幕”以安抚市场或集结盟友支持，并强调美国最初的战争目标中并未包含重新开放霍尔木兹海峡。该分析认为，特朗普可能认为已达成其核心目标（摧毁伊朗海军、导弹等），但这对其中东盟友而言将是战略失误。
        * **NPR** 强调了特朗普发出的混合信号：一方面在社交媒体上声称与伊朗“更合理的政权”进行谈判并取得进展，另一方面又威胁如果海峡不重新开放将摧毁伊朗的能源基础设施。同时，伊朗方面否认与美国进行任何谈判。

* **【主题关键词】能源价格冲击与通胀**
  * **客观事实/量化数据**：
    1. 美国全国普通汽油平均价格已突破每加仑4美元，为2022年8月以来最高水平，较一个月前上涨超过1美元。（WSJ, Bloomberg, Marketplace）
    2. 油价目前约为每桶115美元。（Marketplace）
    3. 有能源顾问警告，如果战争持续，油价可能飙升至每桶150-200美元甚至更高。（Bloomberg）
    4. 美联储主席鲍威尔表示，目前判断战争的经济影响为时过早，能源冲击是继疫情和关税之后的又一供给侧冲击。美联储政策处于可以“等待和观察”的有利位置。（Bloomberg）
  * **共识与分歧**：
    * **共识**：所有播客均将汽油价格飙升与伊朗战争导致的航运中断和供应风险直接关联。高能源价格正在侵蚀消费者购买力，并引发对通胀和美联储政策的担忧。（WSJ, Bloomberg, Marketplace）
    * **分歧**：对经济影响的量化评估和消费者行为反应的看法略有不同。
        * **Marketplace** 提供了更具体的分析：指出汽油价格上涨相当于对消费者征收新税，可能完全抵消2025年减税法案带来的约600亿美元退税所带来的消费提振。如果全年汽油均价维持在4美元，退税的积极影响将被完全抵消。
        * **WSJ** 的债券市场分析指出，通胀担忧（尤其是能源价格）已导致市场对美联储的降息预期从战前的两次，转变为预计今年不会降息，甚至出现了30%的加息概率预期。

* **【主题关键词】美国金融市场与债券**
  * **客观事实/量化数据**：
    1. 美国股市本季度（第一季度）有望创下近四年来最差表现（道指跌近6%，标普500跌7.3%，纳指跌10.5%）。（Bloomberg）
    2. 战争初期，债券作为避险资产上涨，但随后持续遭到抛售。10年期美债收益率已从战前略低于4%升至接近4.5%。（WSJ）
    3. 随着美债收益率上升，抵押贷款利率从多年低点回升至平均约6.3%。（WSJ）
    4. 市场对美联储今年降息的预期已基本消失，甚至开始定价加息的可能性。（WSJ）
  * **共识与分歧**：
    * **共识**：战争引发的能源价格冲击和通胀担忧是导致债券遭抛售、收益率上升的核心原因。股市因战争不确定性而表现糟糕，能源板块是少数表现好的领域。（WSJ, Bloomberg）
    * **分歧**：对债券市场未来走向的看法存在分歧。
        * **WSJ** 报道指出，存在一种“霍尔木兹希望”（Hormuz hopes），即战争可能结束的预期会短暂提振债券。但同时，许多投资者目前仍看好债券，认为无论战争持续与否，其对经济增长的负面影响最终将导致债券上涨（收益率下降）。
        * **Bloomberg** 的评论（来自U.S. Bank Asset Management）指出，本季度除了能源和部分基础设施类资产外，市场“无处可藏”，凸显了资产的普跌和避险的困难。

* **【主题关键词】美国国内政治与经济政策**
  * **客观事实/量化数据**：
    1. **税收**：华盛顿州通过了对百万美元以上收入征收9.9%新税的法律，将于2028年生效。与此同时，密西西比、俄克拉荷马等州计划取消个人所得税，南卡罗来纳州将把最高税率降至2%以下，凸显红蓝州税收分歧。（WSJ）
    2. **关税**：美国最高法院裁定特朗普利用《国际紧急经济权力法》实施关税非法。特朗普随后改用《1974年贸易法》重新征收关税，但该法授权期限最长为150天（至7月中下旬），之后需国会投票延长。相关法律挑战仍在继续。（FT）
    3. **退休金投资**：特朗普政府发布新规，为401(k)等退休金计划投资私募股权、私募信贷等另类资产提供指引，旨在扩大投资选择，但正值私募信贷市场违约上升、波动加剧之际。（FT）
    4. **政府停摆**：国土安全部资金僵局导致部分机构停摆超过40天。TSA员工刚刚收到逾期一个多月的部分工资，但停摆仍未结束，下一笔薪水支付时间未知。停摆期间已有超过500名TSA员工辞职。（NPR, Bloomberg）
  * **共识与分歧**：
    * **共识**：国内政策存在高度争议和不确定性，从税收、贸易到政府运作均陷入僵局或面临法律挑战。（WSJ, FT, NPR）
    * **分歧**：各播客关注点不同，但共同描绘了一个政治极化、政策路径曲折的图景。
        * **WSJ** 和 **FT** 侧重于长期经济政策（税收竞争、贸易战法律基础、退休金改革）的结构性影响。
        * **NPR** 和 **Bloomberg** 更关注政府停摆对具体部门（TSA）运作和员工生活的即时冲击。

# 三、市场分析

1.  **流动性与估值中枢**：
    海外信息共振指向一个“滞胀”环境雏形：地缘冲突（伊朗战争）引发**供给侧能源冲击**，推高全球通胀预期。这导致**美联储降息预期急剧退潮甚至转向加息担忧**，驱动**美债收益率飙升**和**美元维持强势**。对于中国A股及大宗商品市场，传导路径如下：
    *   **利率与估值**：美债收益率作为全球资产定价锚，其上升将压制全球成长股的估值，对A股中估值较高、对外资流动性敏感的板块（如部分科技、消费）形成压力。外资可能因无风险收益率提升和风险偏好下降而阶段性流出。
    *   **汇率与成本**：强势美元虽对人民币构成被动贬值压力，但一定程度上利于出口。然而，**全球航运成本与关键原材料（如石油、衍生化工品）价格飙升**，将直接推高中国制造业的进口成本，侵蚀中下游企业利润。
    *   **风险偏好**：全球股市波动加剧和“无处可藏”的资产表现，将抑制全球风险偏好，不利于新兴市场资产的整体表现。

2.  **行业板块映射**：
    *   **具备做多逻辑的板块/品种**：
        *   **大宗商品：原油、黄金**。地缘风险溢价和供应中断现实直接支撑油价。黄金在滞胀预期和避险需求双重驱动下具备配置价值。
        *   **A股板块**：
            *   **能源/油气开采、油服**：直接受益于油价中枢上移。
            *   **航运（油运）**：霍尔木兹海峡持续关闭或通行效率低下，导致运距拉长、有效运力紧张，推升油运价格。
            *   **部分制造业（如WSJ提及的中国PMI反弹）**：若海外供应链因战争持续受扰，而中国凭借稳定产能和全产业链优势，可能如2020年那样**承接替代性出口订单**，提升全球份额。这利好**机电设备、汽车零部件、化工**等优势出口行业。
            *   **内需基建/建材**：中国自身经济数据反弹，服务业和建筑业活动回升，可能指向国内稳增长政策发力，利好相关板块。
    *   **具备做空或需规避逻辑的板块**：
        *   **大宗商品：对成本敏感的中游制造品**（如部分化工品，若需求无法传导成本）。
        *   **A股板块**：
            *   **高估值成长股（尤其依赖外资的）**：受美债收益率上行压制。
            *   **成本端受油价冲击严重的交运（航空、物流）、下游化工、塑料制品**：利润面临挤压。
            *   **对美出口占比高且可替代性强的行业**：需警惕美国国内政策风险（如FT提到的关税法律纠纷可能带来的贸易环境不确定性）和潜在需求放缓（如Marketplace分析的美国消费者受高油价挤压）。
