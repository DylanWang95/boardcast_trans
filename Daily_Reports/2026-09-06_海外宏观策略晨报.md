# 🌅 2026-09-06 海外宏观与市场博弈晨报

# 宏观策略晨报

**日期：2026年9月6日**


## 一、关注要点

### 1. 【美国防晒品监管改革与新成分获批——FDA审批机制的重大转变】

* **客观事实/量化数据**：美国FDA批准了新型防晒成分bemotrizanol（BEMT），这是**超过25年来**美国批准的首个新型活性防晒成分。该成分于**2005年**首次向FDA提交申请，若今年秋季如期上市，审批周期长达**20年以上**。该成分已在欧洲、亚洲部分地区及澳大利亚使用数十年。2020年国会通过的**CARES法案**（新冠疫情纾困法案）改变了包括防晒品在内的非处方药的监管方式，简化了申请流程，直接推动了此次获批。（来源：【NPR Up First】《From SPF to skin color, sunscreen's effectiveness is complicated》）

* **共识与分歧**：
  * **共识**：所有受访专家均认为美国在防晒品创新方面长期落后于欧洲和亚洲市场，BEMT的获批是公共健康的胜利，但美国在防晒选择多样性上仍落后于欧盟等地区。消费者权益组织EWG与皮肤科医生Adewale Adamson均对FDA审批效率提出批评。（来源：【NPR Up First】）
  * **分歧**：关于防晒建议是否应"一刀切"适用于所有肤色人群，专家之间存在显著分歧。澳大利亚流行病学家David Whiteman和皮肤科医生Adewale Adamson认为，针对不同肤色人群应提供差异化建议，现有"所有人每天都需要涂防晒霜"的公共健康建议"存在严重缺陷"；而宾夕法尼亚大学皮肤科教授Susan Taylor及皮肤颜色学会则坚持认为，有色人种仍应使用防晒霜以预防色素沉着、晒伤及其他非黑色素瘤皮肤癌。（来源：【NPR Up First】）


### 2. 【防晒品SPF标注可靠性危机——澳大利亚检测揭示行业系统性缺陷】

* **客观事实/量化数据**：澳大利亚消费者监督机构Choice于**2025年秋季**对20款市售防晒产品进行SPF检测，结果**16款（80%）** 未达到标注值。这些产品均标注SPF 50或以上，但实际检测值分布在40s、30s、20s甚至更低，其中一款实测SPF仅为**4**。涉及品牌包括Neutrogena、La Roche-Posay、Cancer Council、Banana Boat等主流品牌。SPF测定采用人体在体试验（in vivo test），通过目测皮肤红斑反应来判断，具有高度主观性，同一配方在不同实验室可能测出SPF 50与SPF 30的差异。（来源：【NPR Up First】）

* **共识与分歧**：
  * **共识**：EWG的Alexa Friedman与软物质科学家Anna Wang均承认现有SPF测试体系存在显著不一致性。Anna Wang指出，虽然存在使用塑料替代皮肤的国际标准测试方法，但该方法同样不准确，因为皮肤是复杂的生物材料——对不同波长具有不同的透光性，含有蛋白质、脂质、水分，且表面粗糙有毛发，还会吸收部分成分，塑料无法模拟这些特性。（来源：【NPR Up First】）
  * **分歧**：关于SPF数值差异的实际意义，播客中隐含的观点分歧在于——从数学角度看，SPF 30与SPF 50仅相差1%的UVB阻挡率（97% vs 98%），但消费者通常认为数值翻倍意味着保护力翻倍。播客倾向于认为，无论SPF高低，防晒霜实际保护时间通常不超过2小时，补涂比追求高SPF更重要。（来源：【NPR Up First】）


### 3. 【防晒与皮肤癌预防的循证医学基础——Nambour试验的里程碑意义与局限】

* **客观事实/量化数据**：目前全球唯一一项全面随机对照试验（RCT）——澳大利亚**Nambour试验**，始于1990年代，由Adele Green教授主导，招募了**超过1,600人**。试验发现：对于基底细胞癌（BCC），严格防晒+皮肤检查未显示显著差异；对于鳞状细胞癌（SCC），发病率下降近**40%**；对于黑色素瘤（最致命的皮肤癌），防晒霜使用确实降低了发病率。该试验参与者中**1,600余人中仅有4人非白人**。另一项英国研究显示，最深肤色皮肤的黑色素含量对DNA损伤的保护力是浅色欧洲裔皮肤的**60倍**。美国数据显示，白人黑色素瘤发病率约为黑人的**30倍**。（来源：【NPR Up First】）

* **共识与分歧**：
  * **共识**：Nambour试验被David Whiteman描述为临床医学的"金标准"，且未来不太可能重复此类研究。所有专家均认可该试验是防晒霜预防黑色素瘤建议的"唯一基础"。（来源：【NPR Up First】）
  * **分歧**：关于Nambour试验结果能否外推至有色人种，专家存在分歧。Whiteman和Green认为结果不能直接外推至有色人种，且黑色素瘤在黑人中通常发生在手掌、脚底等非日晒部位（如Bob Marley死于脚趾甲下的黑色素瘤），UV辐射可能不是深肤色人群黑色素瘤的主要风险因素；而Susan Taylor等则认为防晒建议应保持普适性。（来源：【NPR Up First】）


### 4. 【防晒品监管的"美国例外论"——从MAHA到AOC的罕见跨党派共识】

* **客观事实/量化数据**：防晒品在美国被归类为**非处方药（OTC drug）** 进行监管，而在欧盟等地区被归类为**化妆品**，这导致美国对防晒成分设置了极高的审批门槛。防晒品创新被列为"让美国再次健康"（MAHA）战略报告的优先事项，同时也被众议员Alexandria Ocasio-Cortez在2023年的社交媒体视频中公开批评，她表示"在韩国，防晒霜的先进性显而易见，美国远远落后于世界其他地区"。这一议题罕见地获得了跨党派关注。（来源：【NPR Up First】）

* **共识与分歧**：
  * **共识**：无论是保守派的MAHA议程还是进步派的AOC，均认为美国防晒品监管体系需要改革。EWG的Alexa Friedman指出，由于美国漫长的审批流程，消费者无法获得国际市场已有的先进防晒成分。（来源：【NPR Up First】）
  * **分歧**：播客未明确呈现关于如何改革的具体分歧，但隐含了两种路径的张力——通过CARES法案简化行政流程（渐进式改革）vs. 从根本上重新分类防晒品的监管属性（结构性改革）。（来源：【NPR Up First】）

    - 英国研究：最深肤色皮肤的黑色素保护力为浅色皮肤的60倍

    - 澳大利亚已开始推行基于三种肤色类别的差异化防晒建议
  * **独特视角**：播客揭示了防晒品监管中"美国例外论"的困境——美国以"更高标准"自居，却因审批流程过长导致消费者无法获得更先进的防晒技术。同时，播客挑战了"所有人每天都需要涂防晒霜"的普适性公共健康建议，指出该建议缺乏针对不同肤色人群的循证医学支持。此外，播客还揭示了防晒品行业的一个深层矛盾：消费者同时要求防晒品"无毒、不油腻、防水、有效、隐形、便宜"，这些要求在化学层面相互竞争，极难同时满足。
